# THE DARK KNIGHT: GOTHAM'S DESCENT

A atmospheric, 2D turn-based tactical RPG set in the dark, neon-lit underbelly of Gotham City. Built entirely as a single-file, zero-dependency HTML5 application featuring web-synthesized audio, interactive mini-tasks, dynamic combat, and an ominous storyline.

---

## 🦇 Game Overview

The Narrows have been plunged into chaos. A deadly cocktail of Scarecrow's fear toxin and the Riddler's digital gridlock has locked down Gotham City. As Batman, you must navigate through hostile sectors, interrogate thugs, hack encrypted terminals, manage your limited gadgets, and survive a final showdown to save the city before Gotham falls.

---

## ✨ Features

- **Immersive Gotham Noir Aesthetic:** Dark color palettes, rain-slicked visual motifs, CRT scanline toggles, and atmospheric styling.
- **Web Audio API Sound Engine:** Fully synthesized sound effects for CQB strikes, Batarang throws, smoke pellets, UI clicks, victory/defeat chimes, and an ambient low-frequency Gotham drone.
- **Turn-Based Tactical Combat:** 
  - **Strike:** Heavy close-quarters melee damage.
  - **Batarang:** Ranged precision attack (consumes limited ammo).
  - **Smoke Pellet:** Evasion buff to reduce incoming damage.
  - **Detective Scan:** Analyzes enemy weakness and exposes vulnerabilities.
- **Interactive Minigames:** Hacker terminals and code-breaking puzzles encountered between sectors to unlock sector gates and disable toxin generators.
- **Rich Storyline & Multiple Endings:** Sector progression, narrative intermission screens, a climactic boss battle, and branching outcomes (True Victory vs. Gotham Falls).
- **Waynetech Database:** Lore dossier containing files on Batman's equipment, allies, and rogues gallery.

## 🕹️ How to Play

1. **Get the Game:** Ensure you have saved the code generated by Claude as an HTML file (e.g., `batman_game.html`).
2. **Launch:** Double-click `batman_game.html` to open it in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).
3. **Controls:** 
   - Use your mouse/trackpad to click menu buttons, settings toggles, and combat actions.
   - During combat, select your tactical move each turn and watch the battle log for results.
   - Complete hacking minigames by matching sequences or entering correct decryption codes when prompted.

---

## 🛠️ Technical Details

- **Single-File Architecture:** Contains pure HTML, CSS, and modern vanilla JavaScript with no external asset hosting or installation requirements.
- **Zero Dependencies:** Runs natively in any browser offline without requiring local servers, Node.js, or package managers.
